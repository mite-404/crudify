# API reference

This page lists the public exports of `ncrudify` 1.5.0.

## Top-level exports

```ts
import {
  AuditController,
  AuditInterceptor,
  AuditLog,
  AuditLogSchema,
  AuditModule,
  AuditService,
  ConfigModule,
  ConfigService,
  Crudify,
  CrudifyController,
  CrudifyExceptionFilter,
  CrudifyModule,
  CrudifyService,
  DisableRouteGuard,
  NoAudit,
  QueryParser,
  createAuditLogSchema,
  disableRoutes,
} from "ncrudify";

import type {
  AuditLogRecord,
  AuditUserExtractor,
  IAuditOptions,
  ICrudify,
  ICrudifyModuleOptions,
  ICrudifyRoutes,
  IResponse,
} from "ncrudify";
```

## `CrudifyModule`

```ts
@Module({
  imports: [HealthModule, ConfigModule],
})
export class CrudifyModule {
  static forRoot(options?: ICrudifyModuleOptions): DynamicModule;
}
```

`forRoot()` imports `AuditModule` and registers the health, configuration and audit infrastructure.

### `ICrudifyModuleOptions`

```ts
export interface ICrudifyModuleOptions {
  uri?: string;
  audit?: boolean | IAuditOptions;
}
```

| Property | Description                                                                                     |
| -------- | ----------------------------------------------------------------------------------------------- |
| `uri`    | Accepted for backward compatibility and currently ignored. Use `MongooseModule.forRoot()`.      |
| `audit`  | `true`, `false` or `IAuditOptions`. Automatic audit logging is disabled by default.             |

## `Crudify` decorator

```ts
export function Crudify<T>(options: ICrudify): (target: Function) => void;
```

Throws when `options.model.type` is missing.

### `ICrudify`

```ts
export interface ICrudify {
  model: ICrudifyModel;
  routes?: ICrudifyRoutes;
  softDelete?: boolean;
}

export interface ICrudifyModel {
  type: Type;
  cdto?: Type;
  udto?: Type;
  schema?: Schema;
}
```

### `ICrudifyRoutes`

```ts
export interface ICrudifyRoutes {
  config?: Partial<Record<ControllerMethods, IRouteConfig>>;
  exclude?: ControllerMethods[];
  decorators?: MethodDecorator[];
  disableBulk?: boolean;
}

export interface IRouteConfig {
  decorators?: MethodDecorator[];
  disabled?: boolean;
}
```

`ControllerMethods` is:

```ts
type ControllerMethods =
  | "create"
  | "createBulk"
  | "findAll"
  | "findOne"
  | "put"
  | "update"
  | "updateBulk"
  | "delete"
  | "deleteSoft"
  | "deleteBulk"
  | "restore"
  | "restoreBulk"
  | "count";
```

### `disableRoutes`

```ts
export function disableRoutes(
  options: ICrudify,
  prototype: any,
  isSoftDelete: boolean
): ICrudify;
```

Internal helper used by `Crudify`. It normalizes `disableBulk` into `routes.exclude` and stores the `softDelete` metadata. It is exported for advanced use cases.

## `CrudifyController`

```ts
@UseFilters(CrudifyExceptionFilter)
@Controller(":entity")
export class CrudifyController<T, C = Partial<T>, U = Partial<T>> {
  softDelete: boolean;
  modelName: string;

  constructor(
    crudService: CrudifyService<T, C, U>,
    configService?: ConfigService
  );

  create(createDto: C): Promise<T>;
  createBulk(data: C[]): Promise<T[]>;
  findAll(query: any): Promise<IResponse<T>>;
  count(query: any): Promise<number>;
  findOne(id: string): Promise<T | null>;
  put(id: string, updateDto: Partial<U>): Promise<T | null>;
  updateBulk(body: { filter: any; updateDto: any }): Promise<any>;
  restoreBulk(body: { filter: any }): Promise<any>;
  update(id: string, updateDto: Partial<T>): Promise<T | null>;
  deleteBulk(body: { filter: any }): Promise<any>;
  delete(id: string): Promise<T | null>;
  deleteSoft(id: string): Promise<T | null>;
  restore(id: string): Promise<T | null>;
}
```

The route decorators are generated by `@Crudify`. Extend this class and call `super(service)` in your constructor.

### Runtime route checks

`CrudifyController` calls `ConfigService.isRouteEnabled(modelName, route)` before executing a route when `ConfigService` is available. If the route is disabled, it returns `ConfigService.notEnabledResponse(...)`.

## `CrudifyService`

```ts
@Injectable()
export class CrudifyService<T, C = Partial<T>, U = Partial<T>> {
  constructor(protected readonly model: Model<T>);

  create(createDto: C): Promise<T | any>;
  createBulk(data: C[]): Promise<T[] | any>;
  findAll(query?: QueryFilter<T>): Promise<IResponse<T>>;
  findOne(filter: QueryFilter<any>): Promise<T | null>;
  count(filter: Record<string, any>): Promise<number>;
  put(id: string, updateDto: UpdateQuery<U>): Promise<T | null>;
  update(id: string, updateDto: UpdateQuery<T>): Promise<T | null>;
  updateBulk(filter: any, updateDto: UpdateQuery<U>): Promise<any>;
  delete(id: string): Promise<T | null>;
  deleteBulk(filter: any): Promise<any>;
  softDelete(id: string): Promise<T | null>;
  softDeleteBulk(filter: any): Promise<any>;
  restore(id: string): Promise<T | null>;
  restoreBulk(filter: any): Promise<any>;
}
```

`QueryFilter` and `UpdateQuery` are Mongoose types:

```ts
import { QueryFilter, UpdateQuery } from "mongoose";
```

### Response shape

```ts
export interface IResponse<T> {
  results: T[];
  total: number;
  page: number;
}
```

`page` is one-based:

```ts
page = limit > 0 ? Math.floor(skip / limit) + 1 : 1;
```

## `QueryParser`

```ts
export class QueryParser {
  static operatorsMap: Record<string, string>;

  static parse(query?: Record<string, unknown>): {
    filters: Record<string, any>;
    populate: any[];
    sort: Record<string, 1 | -1>;
    skip: number;
    limit: number;
  };

  static castValue(value: unknown): any;
}
```

### `operatorsMap`

```ts
{
  eq: "$eq",
  ne: "$ne",
  gt: "$gt",
  gte: "$gte",
  lt: "$lt",
  lte: "$lte",
  starts: "$regex",
  ends: "$regex",
  cont: "$regex",
  excl: "$not",
  in: "$in",
  notin: "$nin",
  isnull: "$exists",
  notnull: "$exists",
  between: "$gte"
}
```

See [Query parser](query-parser.md) for the complete query language.

## `CrudifyExceptionFilter`

```ts
@Catch()
export class CrudifyExceptionFilter implements ExceptionFilter {
  catch(exception: unknown, host: ArgumentsHost): void;
}
```

Maps `HttpException`, Mongoose `CastError`, Mongoose `ValidationError`, duplicate key errors and unknown errors. See [Exceptions](exceptions.md).

## `DisableRouteGuard`

```ts
@Injectable()
export class DisableRouteGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean;
}
```

Always returns `false`. It is applied to routes excluded or disabled at build time and causes a `403 Forbidden` response.

## `ConfigModule`

```ts
@Global()
@Module({
  imports: [
    MongooseModule.forFeature([{ name: Config.name, schema: ConfigSchema }]),
  ],
  controllers: [ConfigController],
  providers: [ConfigService],
  exports: [ConfigService],
})
export class ConfigModule {}
```

`ConfigModule` is imported by `CrudifyModule`. It registers:

- `GET /config`
- `PUT /config/:model`
- `POST /config/reload`

## `ConfigService`

```ts
@Injectable()
export class ConfigService implements OnModuleInit {
  constructor(configModel: Model<Config>);

  onModuleInit(): Promise<void>;
  load(): Promise<void>;
  isRouteEnabled(model: string, route: string): boolean;
  getAll(): Record<string, any>;
  updateConfig(
    model: string,
    updates?: Partial<{
      enabled: boolean;
      routes: Partial<Record<ControllerMethods, boolean>>;
      props: Partial<Record<string, any>>;
    }>
  ): Promise<void>;
  notEnabledResponse(
    modelName: string,
    route: string
  ): {
    success: false;
    status: 403;
    message: string;
  };
}
```

### `Config` document shape

```ts
{
  modelName: string;
  enabled?: boolean;
  routes?: Partial<Record<ControllerMethods, boolean>>;
  props?: Partial<Record<string, any>>;
}
```

`ConfigService.updateConfig()` only persists `enabled`, `routes` and `props`. The `Config` class and `ConfigController` are not exported at the top level.

See [Runtime configuration](config.md).

## Audit exports

### `AuditModule`

```ts
@Global()
@Module({})
export class AuditModule {
  static forRoot(options?: IAuditOptions): DynamicModule;
}
```

`forRoot()` always provides `AuditService`, `AuditController` and the audit model. It registers `AuditInterceptor` as `APP_INTERCEPTOR` only when `options.enabled` is `true`.

### `IAuditOptions`

```ts
export interface IAuditOptions {
  enabled?: boolean;
  collectionName?: string;
  userExtractor?: AuditUserExtractor;
}

export type AuditUserExtractor = (
  request: any
) => string | null | undefined;
```

### `AuditLogRecord`

```ts
export interface AuditLogRecord {
  user: string;
  action: string;
  entityId: string | null;
  details: Record<string, any>;
  createdAt?: Date | string;
}
```

### `AuditLog`

```ts
export class AuditLog extends Document implements AuditLogRecord {
  user: string;
  action: string;
  entityId: string | null;
  details: Record<string, any>;
}
```

The schema uses timestamps and the collection `audit_logs` by default.

### `AuditLogSchema` and `createAuditLogSchema`

```ts
export const AuditLogSchema: Schema;

export function createAuditLogSchema(
  collectionName?: string
): Schema;
```

`createAuditLogSchema()` creates a schema with a custom collection name.

### `AuditService`

```ts
@Injectable()
export class AuditService {
  constructor(auditLogModel: Model<AuditLog>);

  log(record: AuditLogRecord): Promise<AuditLog>;
  findAll(query?: Record<string, any>): Promise<AuditLog[]>;
  findOne(id: string): Promise<AuditLog | null>;
}
```

`findAll()` uses `QueryParser` and sorts by `createdAt` descending when no sort is provided.

### `AuditInterceptor`

```ts
@Injectable()
export class AuditInterceptor implements NestInterceptor {
  constructor(
    auditService: AuditService,
    connection: Connection,
    options?: IAuditOptions
  );

  intercept(
    context: ExecutionContext,
    next: CallHandler
  ): Promise<Observable<any>>;
}
```

Registered automatically as a global interceptor when audit logging is enabled. It can also be instantiated manually for advanced use cases.

### `NoAudit`

```ts
export function NoAudit(
  ...actions: string[]
): ClassDecorator & MethodDecorator;
```

Stores audit exclusions on a controller class or a route handler. See [Audit logging](audit.md).

### `AuditController`

```ts
@NoAudit()
@ApiTags("Audit")
@Controller("audit")
export class AuditController {
  findAll(query: Record<string, any>): Promise<AuditLog[]>;
  findOne(id: string): Promise<AuditLog | null>;
}
```

Exposes:

- `GET /audit`
- `GET /audit/:id`

## Internal exports

The following are used internally and are not exported from the package root:

- `Config` entity and `ConfigController`.
- `HealthModule`, `HealthController` and `HealthResponse`.
- `CrudifyRoutes` and `CrudifyRoutesDecorator`.
- `ControllerMethods`, `IRouteConfig`, `ICrudifyModel` as standalone imports.
- Audit constants and audit utility functions.

Their shapes are documented where relevant, but they are not part of the stable public API.
